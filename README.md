# ORP Prili App Archives

This repository contains downloadable ZIP archives of four iOS SwiftUI app projects:

- `app_archives/Daily_Brain.zip`
- `app_archives/Fridge_Rescue.zip`
- `app_archives/Plant_Doctor.zip`
- `app_archives/Pocket_First_Aid.zip`

`Photo Sweep` is intentionally excluded.

Each archive contains a full Xcode project source package, excluding local Git history, build caches, and macOS service files.

To download everything from GitHub, use the green **Code** button and choose **Download ZIP**, or clone the repository:

```bash
git clone https://github.com/korniychukg-sudo/-orp_prili.git
```
